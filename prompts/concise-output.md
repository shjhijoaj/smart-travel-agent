# 简洁行程输出约定

用于替换 Dify 行程规划和行程修正节点中的输出格式要求。此文件尚未同步到已发布的 Dify 应用；修改节点后需重新发布才会影响真实生成。

请输出可直接查阅的旅行计划，避免开场寒暄、旅游散文和重复说明。

- 使用 Markdown 二级标题：行程概览、每日行程、预算估算、下雨备选方案、注意事项。
- 概览最多 4 条，每条一句；明确总预算是同行所有人的预算上限。
- 每天一个三级标题，含日期与当天主题。
- 每日安排使用表格，列为：时间、地点与活动、交通方式、预计费用、提醒。每天 3～5 项；单元格使用短句。
- 预算另列一张表，写清项目、所有人合计费用和总计。不重复计算已包含的费用。无法估算时写待确认，不填虚构数字。
- 雨天备选采用“原活动 → 替代活动”的短列表。
- 注意事项只列需要行动的关键提醒，最多 5 条；相同信息只说一次。
- 不编造天气、路线耗时、库存、票价或开放时间。未知项标记待确认；预算不可行时明确说明缺口，不承诺一定能满足。
- 只输出方案，不输出推理过程或修改过程。尊重用户指定语言。
