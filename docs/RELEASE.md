# v0.4.0 发布记录

日期：2026-09-22。面向本地与单实例使用。

## 本版功能

- Dify Chatflow 旅行知识检索、规划、检查与修正，保留返回的引用资料。
- SSE 转发节点进度与正文增量，过滤推理内容，只保存完整方案。
- 注册、登录、改密、会话撤销与账号间历史隔离。
- SQLite 持久化主动填写的长期偏好，支持编辑、删除和按次关闭。
- 结构化日程编辑、Nominatim / OSRM 道路估算和规则触发的局部调整建议。
- 天气快照、预算检查、历史版本、Markdown / 打印 / 日历导出。
- 固定场景评测和运行次数、耗时、成功率、令牌 / 成本估算。
- GitHub 主页、桌面与手机展示图片、Docker 部署和持续集成配置。

## 自动回归

本次发布准备在干净的源码目录中复验：

- 59 项 pytest 自动化测试。
- 2 个工作流规则用例：正常预算与预算超限。
- 2 个固定评测场景：预算提示与单日旅行。
- 浏览器回归：安全文本渲染、表格和卡片、历史、版本、导出、失败恢复、账号与长期偏好。

测试不调用真实模型；远端构建结果以仓库 [Actions](https://github.com/shjhijoaj/smart-travel-agent/actions) 为准。

## 既有真实联调记录

项目开发阶段在本机完成过 Open-Meteo 天气查询、Dify 生成、Docker 启动及账号偏好的容器重启持久化检查。原始记录保留在开发目录中，未随公开源码上传。

一次广州两日样例返回 1,066 个增量事件、1,659 字符正文和 5 条知识库来源，首段正文约 45 秒。这是单次联调观测，不是性能基准，也不表示所有建议经过事实核验。

## 构建与复现

执行 `python scripts/build_release.py` 生成 `release/smart-travel-agent-v0.4.0.zip` 及 SHA256 文件。包内包含源码哈希清单 `MANIFEST.json`，排除密钥、数据库、虚拟环境、原始测试记录和个人交接文件；仅收录经过整理的公开展示图片。

Dify DSL 在新工作区导入后需要重新选择模型和知识库。安装与运行见 [README](../README.md)，真实联调方式见 [测试说明](testing.md)。

## 当前限制

长期偏好不包含自动记忆提取或向量检索。OSRM 返回驾车道路估算，不代表实时公交、步行或拥堵时间。局部调整写入规则建议，不会自动确认营业时间或完成预订。天气和知识库是查询时快照，样例知识主要覆盖广州。

公网部署需另行配置 HTTPS、注册与用量管理、备份和运维。仓库目前未指定开源许可证。
