# 项目完成范围

v0.4.0 已完成真实天气、Docker、在线 Dify、账号认证、SSE、持久偏好、结构化日程编辑、地图路线估算、局部调整建议、固定案例评测与运行遥测。验收数字见 RELEASE.md。

已有旅行表格/手机卡片、历史版本、预算与行程检查、知识来源展示、导出和自动回归。这些是可演示、可验证的工程能力。

后续扩展与本轮验收分开：

1. 公交/步行路线与实时交通耗时，需选定供应商和额度；当前 OSRM 是道路估算。
2. 知识库更新策略及检索准确率评估，补充更多目的地资料。
3. 用户授权的自动记忆提取、向量语义召回和纠错/遗忘机制；当前只有显式持久化偏好。
4. 公网账户治理、模型调用配额、HTTPS、备份、监控与负载测试。
5. 远端 GitHub Actions 验证；此次提供配置，推送后才能取得运行记录。

参考工程使用不同技术栈，也包含规划性文档。不会用未经测试的完成率、吞吐量或“完全一致”描述本项目。
